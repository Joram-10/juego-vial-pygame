# Juego Vial (Pygame)

Juego educativo hecho con Pygame para practicar las señales de tránsito de México.

## Cómo se juega
1. En el menú elige tu personaje: **1** para Ana (peatón) o **2** para Luis (conductor).
2. Nivel 1: aparece la señal de **ALTO** y respondes con **A** o **B** qué debes hacer.
3. Nivel 2: aparece la señal de **CEDA EL PASO** y respondes con **A** o **B** qué significa.
4. Si respondes bien los dos niveles ganas; si fallas, el juego te lo indica.

Las señales se dibujan con código (sin imágenes externas).

## Requisitos
- Python 3.8 o superior
- Pygame: `pip install pygame`

## Ejecutar
```
python juego_vial.py
```
